# Share Luisa Career Direction

## Simplest Setup

Host it at:

```text
https://jinmi.tech/luisa-career-direction/
```

Then share:

```text
Luisa, here is your career direction workspace:
https://jinmi.tech/luisa-career-direction/

Use this shared PIN when you want to open the private planning workspace.
PIN: 2468
```

## Who Can Edit?

You and Luisa use the same PIN. Anyone with the PIN can edit the online workspace.

Share the PIN if you want Luisa to update applications, STAR notes, weekly reviews, or route decisions herself.

## Hostinger Upload

In Hostinger:

```text
hPanel -> Websites -> Manage -> File Manager -> public_html
```

Create this folder:

```text
luisa-career-direction
```

Upload the contents of this project folder into it, including:

- `index.html`
- `styles.css`
- `app.js`
- `api/`
- `data/`

The shared online data file is created automatically after the first online save.
