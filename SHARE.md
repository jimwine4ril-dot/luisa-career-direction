# Share Luisa Career Direction

## Simplest Setup

Host it at:

```text
https://jinmi.tech/luisa-career-direction/
```

Then share:

```text
Luisa, here is your career direction workspace:
https://jinmi.tech/luisa-career-direction/

Use this PIN when you want to open the private planning workspace.
Luisa PIN: 1357
```

## Who Can Edit?

You and Luisa have different PINs. Either PIN opens the same online workspace.

Share Luisa's PIN if you want her to update applications, STAR notes, weekly reviews, or route decisions herself.

## Hostinger Upload

In Hostinger:

```text
hPanel -> Websites -> Manage -> File Manager -> public_html
```

Create this folder:

```text
luisa-career-direction
```

Upload the contents of this project folder into it, including:

- `index.html`
- `styles.css`
- `app.js`
- `api/`
- `data/`

The shared online data file is created automatically after the first online save.
